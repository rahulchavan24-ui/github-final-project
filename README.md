
# Simple Interest Calculator

## About
This project is a simple Bash calculator that calculates simple interest using the principal amount, annual interest rate, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Requirements
- Bash shell
- Terminal or command-line interface

## How to Run
1. Open a terminal.
2. Run `bash simple-interest.sh`.
3. Enter the principal, rate, and time when prompted.

## Example
Principal: 1000
Rate: 5
Time: 2 years

Simple Interest: 100
